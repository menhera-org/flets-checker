# フレッツ光IPv6アドレスチェッカー

IPv6アドレスから、フレッツ光・光コラボの回線かどうか、NTT東日本・西日本のどちらかを調べるツールです。ASNに基づくVNEの推定と、NGN・BGPのプレフィックスも表示します。

HTMLとJavaScriptだけで動作します。ビルドやパッケージのインストールは不要ですが、判定には外部APIとの通信が必要です。

## 使い方

1. [index.html](index.html)をブラウザーで開きます。JavaScriptを有効にしてください。
2. 調べたいIPv6アドレスを入力します。「自分のアドレスを入力」を押すと、接続元のIPv6アドレスを入力できます。
3. 「実行」を押して結果を確認します。

アドレスの自動取得には、IPv6で通信できる環境が必要です。取得しただけでは判定は始まらないので、その後に「実行」を押してください。

入力するのはIPv6アドレスだけです。`2001:db8::1`のような省略形や、`::ffff:192.0.2.1`のようなIPv4を含む表記にも対応しています。これらの例は説明用です。`/64`などのプレフィックス長、`[...]`の角括弧、`%eth0`などのゾーン識別子は付けません。

## 結果の見方

| 項目 | 意味 |
| --- | --- |
| フレッツ光の区別 | NGN照会APIによるNTT東日本・西日本の判定。光コラボも含みます。 |
| VNE | IPv6のIPoE接続を提供する事業者。取得したASNと、このツールの対応表から推定します。 |
| NGNプレフィックス | NGN照会APIが返したアドレス範囲。NGNは、フレッツ光で使われるNTTの次世代ネットワークです。 |
| ASN | BGPの経路情報で使われるネットワークの識別番号。照会結果に複数ある場合は先頭のASNを表示します。 |
| ネットワーク名 | RIPEstatが返したASNの登録組織名。 |
| BGPプレフィックス | RIPEstatで見つかった経路のアドレス範囲。NGNプレフィックスと一致するとは限りません。 |

VNE名やネットワーク名は、契約先のプロバイダー名や料金プランを特定するものではありません。表示するサービス名はASNの対応表に基づくため、そのサービスを実際に契約・利用していることまでは確認できません。通信速度や接続の正常性、IPv4 over IPv6の利用状況も、このツールでは確認しません。

VNEの対応表は、2026年11月18日時点のすべてのVNEを網羅しています。「不明なVNE」は、ASNを取得できない場合や、取得したASNをVNEに対応付けられない場合に表示されます。`AS0`とBGPプレフィックスの`?`は、情報を取得できなかった場合の表示です。

## 判定の仕組みと照会先

ブラウザーから、次の順に外部APIへ問い合わせます。

1. 入力したIPv6アドレスを `https://looking-glass.nc.menhera.org/ngn_query?q=...` に送信し、NGNの地域とプレフィックスを取得します。
2. NGNプレフィックスの先頭アドレスを[RIPEstat Network Info API](https://stat.ripe.net/docs/data-api/api-endpoints/network-info)に送り、ASNとBGPプレフィックスを取得します。NGNプレフィックスがない場合は、入力したアドレスを照会します。
3. 先頭のASNを[index.html](index.html)内の`asnToVne`の対応表でVNE名に変換し、[RIPEstat AS Overview API](https://stat.ripe.net/docs/data-api/api-endpoints/as-overview)からASNの登録組織名を取得します。

「自分のアドレスを入力」は、これらとは別に `https://v6.ip.menhera.org/` に接続し、返された接続元アドレスを入力欄に設定します。

判定結果は、照会先のデータと、このツールの対応表に依存します。外部サービスに接続できない場合は、エラーが表示されたり、一部の情報を取得できなかったりします。

## 配置と変更

静的サイトとして配置できます。配信に必要なのは`index.html`だけで、アプリケーションサーバーは不要です。ホスティング先でContent Security Policyを設定する場合は、ページ内のスクリプト・スタイルと、上記APIへの接続を許可する必要があります。

画面、スタイル、判定処理、ASNとVNEの対応表は、すべて`index.html`にあります。対応するVNEを更新するときは、`asnToVne`を編集します。

IPv6入力の正規表現は、[RFC 3986 §3.2.2](https://www.rfc-editor.org/rfc/rfc3986#section-3.2.2)の`IPv6address`の文法に基づきます。[RFC 4291 §2.2](https://www.rfc-editor.org/rfc/rfc4291#section-2.2)の通常表記、省略表記、IPv4を含む表記を扱います。

## 入力検証のテスト

Dockerが使える環境では、リポジトリのルートで次を実行できます。Node.jsは使い捨てのコンテナー内だけで実行します。

```sh
docker run --rm --network none -v "$PWD:/work:ro" -w /work node:24-alpine node tests/ipv6.test.mjs
```

テストは、実際のページ内スクリプトから入力用の正規表現を取得し、正常・異常なアドレスと必須入力の指定を確認します。外部APIへの通信や画面表示は検証しません。
